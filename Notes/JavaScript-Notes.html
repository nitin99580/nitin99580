Chapter 1: Variables & Data Types

1. Overview

A variable is a named box that stores a value. We use variables to keep test data like usernames, URLs and status codes.

Every value has a data type, such as string, number or boolean. The type tells us what kind of value it is.

2. Core Concepts

2.1 let

let creates a variable whose value can change later.

let userName = "Amit";
console.log(userName);
userName = "Neha";
console.log(userName);

Output:

Amit
Neha

We cannot declare the same let variable twice in the same block.

let count = 1;
let count = 2;

Output:

SyntaxError: Identifier 'count' has already been declared

2.2 const

const creates a variable that cannot be reassigned. We use it for values that should not change, like a base URL.

const baseUrl = "https://test.com";
console.log(baseUrl);
baseUrl = "https://dev.com";

Output:

https://test.com
TypeError: Assignment to constant variable.

With objects and arrays, we cannot reassign the variable. But we can still change what is inside.

const user = { name: "Amit" };
user.name = "Neha";
console.log(user);
const browsers = ["chrome"];
browsers.push("firefox");
console.log(browsers);

Output:

{ name: 'Neha' }
[ 'chrome', 'firefox' ]

2.3 var

var is the old way to create variables. It can be declared again, it is hoisted (we can use it before the line where we declare it, and it gives undefined), and it ignores block { } scope.

console.log(status);
var status = "pass";
console.log(status);
if (true) {
  var browser = "chrome";
}
console.log(browser);

Output:

undefined
pass
chrome

var allows the same name again:

var count = 1;
var count = 2;
console.log(count); // 2

let respects the block. So the variable is not visible outside { }:

if (true) {
  let browser = "chrome";
}
console.log(browser);

Output:

ReferenceError: browser is not defined

Rule: use const by default, use let when the value must change, and avoid var.

2.4 string

A string is text. We can write it with double quotes, single quotes or backticks. Backticks let us put variables inside with ${ }.

const firstName = "Amit";
const course = 'JavaScript';
const message = `Hello ${firstName}`;
console.log(firstName);
console.log(course);
console.log(message);

Output:

Amit
JavaScript
Hello Amit

2.5 number

JavaScript has one number type for both whole numbers and decimals. Wrong math gives special values like Infinity and NaN (Not a Number).

const statusCode = 200;
const price = 99.5;
console.log(statusCode + price); // 299.5
console.log(10 / 0);             // Infinity
console.log("abc" * 2);          // NaN

2.6 boolean

A boolean has only two values: true or false. Comparisons also give a boolean.

const isLoggedIn = true;
const isAdmin = false;
console.log(isLoggedIn); // true
console.log(isAdmin);    // false
console.log(5 > 3);      // true

2.7 null

null means "empty on purpose". We set it ourselves when there is no value yet.

let errorMessage = null;
console.log(errorMessage); // null

2.8 undefined

undefined means a value was never given. JavaScript sets it by itself, for example for a variable with no value or a missing object property.

let token;
console.log(token);    // undefined
const user = { name: "Amit" };
console.log(user.age); // undefined

2.9 typeof

typeof tells us the type of a value as a string. Note: typeof null gives object (an old JavaScript bug), and arrays also give object.

console.log(typeof "Amit");          // string
console.log(typeof 200);             // number
console.log(typeof true);            // boolean
console.log(typeof undefined);       // undefined
console.log(typeof null);            // object
console.log(typeof { name: "Amit" }); // object
console.log(typeof [1, 2, 3]);       // object
console.log(typeof function () {});  // function
