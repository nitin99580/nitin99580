      Daily session format (1 hour –2 hour):

      5–10 min Recall (no notes)
      Write answers to 3 questions from yesterday.

      60 min Course + Code

      10 min Notes (1-page style)
      Add bullets + 1 snippet + 1 mini-task.

      This is the anti-forgetting system.
